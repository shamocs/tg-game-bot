# Задача 1. Создание заготовки чат-бота для Telegram

**Описание:** 
Разработать базовую структуру (заготовку) Telegram-бота, который умеет определять команду пользователя, выбирать соответствующую игру или сценарий и отвечать на следующие базовые команды:

## Доступные команды

*   `/about` — выводит краткую информацию о боте.
*   `/authors` — выводит информацию об авторах проекта.
*   `/help` — выводит информацию обо всех доступных командах. 
    * *Примечание:* должна быть предусмотрена возможность запуска команды с аргументом (например, `/help about` для вывода подробной справки по конкретной команде).
